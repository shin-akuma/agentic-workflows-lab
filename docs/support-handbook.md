## Contact Support

Standard support operates Monday to Friday, 09:00-17:00 UTC, excluding public holidays.
Outside those hours, only critical incidents receive an on-call response.

## Report an Incident

Include an incident identifier, impact, start time, and mitigation attempted.
Do not include credentials or customer personal data.

## Escalate an Incident

Escalate critical incidents to <incident-lead@example.com>.

## Response Targets

Critical incidents receive an initial response within 30 minutes, any time.
High-severity requests receive a response within 2 support hours.
Normal requests receive a response within 1 support day.

See the [service policy](service-policy.md) for authoritative commitments.
